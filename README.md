# 🚀 CryptoCurrency Tracker

A modern cryptocurrency tracking web application built with React.js that provides real-time market data, interactive price charts, and detailed information about cryptocurrencies. The application fetches live data from a cryptocurrency API and presents it through a clean, responsive, and user-friendly interface.

## ✨ Features

- 📈 Real-time cryptocurrency prices
- 🔍 Search cryptocurrencies by name
- 📊 Interactive historical price charts
- 💹 Market statistics and coin details
- 🎠 Trending coins carousel
- 🌍 Select different currencies
- 📱 Fully responsive design
- ⚡ Fast and dynamic user interface

---

## 🛠️ Tech Stack

### Frontend

- React.js
- Material UI
- React Router DOM
- Axios
- Chart.js
- React ChartJS 2
- React Alice Carousel

### API

- Cryptocurrency Market API (CoinGecko)

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Prashant23y/CryptoCurrency-Tracker.git
```

### Navigate to the project

```bash
cd CryptoCurrency-Tracker
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm start
```

The application will run at:

```
http://localhost:3000
```
